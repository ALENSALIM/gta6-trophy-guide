Leonida Legend — an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: the official list with saved progress, filters and a spoiler setting, a roadmap to the platinum, and a guide to each trophy that cites its sources. Free and open source.

## Run it

```sh
node serve.ts
# open http://localhost:8080 in a desktop browser
```
